How to Deploy via GitHub to Cloudflare Pages

1

Push to GitHub

Push this repository to your GitHub account (public or private).

2

Connect to Pages

In Cloudflare Dashboard, go to Workers & Pages → Create application → Pages → Connect to Git. Select this repo and set Build output directory to web.

3

Bind R2 Bucket

Under project Settings → Functions → R2 bucket bindings, add variable BUCKET mapped to your bucket.

4

Plug into Mod

Copy your Pages URL (e.g. https://your-site.pages.dev/api/upload) into the mod's configuration.

Privacy & Transparency Guarantee

NexusMods Safe
  • Zero Telemetry: No analytics, tracking tokens, user identifiers, or game telemetry are ever transmitted or stored.
  • Image Data Only: The endpoint strictly receives rendered 192x192 PNG character avatars for Discord Rich Presence display.
  • Offline Resilient: If the user is offline or has no internet connection, the mod gracefully defaults to the standard game logo without any errors or delays.
  • Deterministic Deduplication: Images are hashed using SHA-256 to eliminate duplicate uploads and minimize storage.
